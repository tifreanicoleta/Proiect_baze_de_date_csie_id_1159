# Proiect_baze_de_date_csie_id_1159
Database project for managing an IT equipment store, developed in Oracle SQL for the university Database course. Includes DDL/DML and complex queries.


Technologies & Tools used:

Language: SQL 
Environment: Oracle SQL Developer
Diagrams (Conceptual Modeling)dbdiagram.io

## 📖 Description
This project focuses on the design and implementation of a relational database for managing the core operations of an IT equipment store. It covers the complete lifecycle from conceptual modeling to advanced database querying and optimization.

Key Features:

*Relational Schema:* Designed tables for managing products, categories, suppliers, customers, orders, payment methods, and delivery options, enforcing strict integrity constraints (Primary/Foreign Keys, Check, Unique). *Data Management (DML):* Populated tables with realistic test data and implemented complex data manipulation scripts (including `MERGE` and conditional updates).
*Advanced Queries:* Developed complex queries involving multi-table joins, subqueries, grouping (`GROUP BY`, `HAVING`), set operations (`UNION`, `MINUS`), and analytical functions.
