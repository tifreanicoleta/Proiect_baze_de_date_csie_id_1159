# Proiect_baze_de_date_csie_id_1159

Database project for managing an IT equipment store, developed in Oracle SQL for the university Database course. Includes DDL/DML and complex queries.


## Technologies & Tools used:

- Language: SQL 
- Environment: Oracle SQL Developer
- Diagrams (Conceptual Modeling): dbdiagram.io

##  Description
This project focuses on the design and implementation of a relational database for managing the core operations of an IT equipment store. 

The database includes information about:
- products
- categories
- suppliers
- customers
- orders
- payment methods
- delivery options

The project includes the database design, table creation, test data and SQL queries.

## Main features:
- Created the database tables and relationships
- Used Primary Keys and Foreign Keys
- Added constraints such as `CHECK` and `UNIQUE`
- Inserted test data into the tables
- Used `INSERT`, `UPDATE` and `DELETE`
- Used `JOIN` queries
- Used `GROUP BY` and `HAVING`
- Used subqueries
- Used `UNION` and `MINUS`
- Used `MERGE`
